# CriticalGaming

## Descrição

O **CriticalGaming** é um projeto acadêmico desenvolvido como trabalho final da Unidade 02 da disciplina de Desenvolvimento Front-End.

O projeto é composto por 17 páginas HTML, estilizadas com CSS3, que apresentam informações sobre jogos, resenhas, rankings, gêneros e interfaces de navegação, além de páginas destinadas a login, cadastro e administração.

Seu principal objetivo é oferecer um espaço para explorar diferentes jogos e conhecer as opiniões dos usuários sobre eles.

**Este projeto possui finalidade exclusivamente acadêmica e educacional.** Nenhuma imagem ou informação utilizada tem finalidade comercial.

## Requisitos

Para visualizar e editar o projeto, recomenda-se utilizar:

- **Sistema operacional:** Windows 10 ou superior.
- **Editor de código:** Visual Studio Code (versão recente).
- **Navegadores compatíveis:**
  - Google Chrome (versão recente).
  - Microsoft Edge (versão recente).
  - Mozilla Firefox (versão recente).

## Extensões do Visual Studio Code

Para facilitar o desenvolvimento e a visualização do projeto, recomenda-se instalar as seguintes extensões:

- **Live Server:** permite executar o projeto em um servidor local e atualizar automaticamente o navegador após salvar alterações.
- **IntelliSense for CSS class names in HTML:** auxilia na identificação e no preenchimento automático de classes CSS nos arquivos HTML.
- **Open Browser Preview:** permite visualizar páginas diretamente no ambiente do Visual Studio Code.

> **Observação:** o Live Server é a extensão utilizada no procedimento de execução descrito abaixo. As demais são ferramentas auxiliares e não são obrigatórias.

## Como executar o projeto

1. Abra o Visual Studio Code.
2. Selecione **Arquivo → Abrir Pasta** e escolha a pasta raiz do projeto.
3. Certifique-se de que a extensão **Live Server** está instalada.
4. Localize e abra o arquivo `index.html`.
5. Clique com o botão direito no arquivo e selecione **Open with Live Server** ou utilize a opção **Go Live** na barra de status do Visual Studio Code.
6. O projeto será aberto automaticamente no navegador padrão.
7. Para visualizar alterações realizadas no código, basta salvar o arquivo. O Live Server atualizará a página automaticamente.
